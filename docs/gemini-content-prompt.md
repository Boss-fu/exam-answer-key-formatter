# 給 Gemini（或其他 AI）產生詳解內容用的 Prompt

用途：讓另一個 AI（例如 Gemini）先把考卷內容解析成 CSV，人再把 CSV 交給 Claude 轉成正式排版的 Word 詳解檔。

---

請幫我把附上的整份考卷逐題解析，輸出成一份 CSV 檔案，欄位如下（第一列是標題列）：

`題號,答案,共用說明,A選項說明,B選項說明,C選項說明,D選項說明`

規則：

**答案欄**：填正確選項的字母（A/B/C/D）。如果沒有提供標準答案卷，你可以自己判斷，但每個選項說明的內容必須能支持這個答案。

**共用說明欄**：只有在多個選項需要靠同一個概念或計算才能判斷時才填寫這一小段說明；如果各選項各自獨立對錯，這一欄留空，不要硬湊內容。

**A/B/C/D選項說明欄**：每一欄的內容格式固定是「正確：理由」或「錯誤：理由」（不要加上"(A)"這種標籤），理由盡量濃縮在一行，大約30字以內。

**內容範圍限制（很重要）**：所有說明只能用「國中課綱」教過的概念和講法，絕對不可以使用高中課綱才教的公式或正式定義（例如物理不要用司乃耳定律、正式的折射率公式；不要用任何國中沒教過的專有名詞或公式）。如果不確定某個講法是否超出國中範圍，就改用比較口語、定性的講法。

**數學公式**：只有科學記號、根號、分數、指數/上標、下標、希臘字母、特殊單位符號（攝氏／華氏度等）這類無法直接打字正常顯示的內容，才用純文字 `$...$` 包住；純數字加單位（例如 5cm/s、60g、100cm）不要加 `$`。只包住真正需要特殊排版的那一小段，不要整句都包進去。

**絕對不可以自己捏造**：如果題幹、圖形、選項、器材、答案等資訊看不清楚或不足，就在對應欄位裡直接寫「需人工確認」加上具體原因，不要自己編造題意、數字、圖形、器材條件或答案。

**輸出格式要求**：純 CSV，UTF-8 編碼，逗號分隔，欄位內容如果有逗號或換行請用雙引號包住（標準 CSV 格式）；不要輸出任何 CSV 以外的說明文字，直接給我完整檔案內容。

---

拿到 CSV 之後，交給 Claude（或依 `skill/SKILL.md` 規則跑 `code/build_from_json.js`）重新核對答案一致性、國中課綱範圍、需人工確認標示，再轉成 Word 排版。
