# 學生詳解本規則：國文、社會（黃金模擬考精簡版）

> 2026-10-03 建立。依據 1011 黃金模擬考的實際成品整理：
> `國H 原檔.docx`（考卷）、`國文詳解H.docx`（老師原詳解）→ `國文H詳解本(精簡).pdf`；`社會N.docx`（考卷）→ `社會N詳解本(精簡).pdf`。
> 參考了京燁主任的 zizi-solution skill，但**以這兩份成品為準**。
>
> **適用範圍**：國文、社會的「學生考後複習用詳解本」。
> **理化先不採用這份規則**：理化、數學的詳解照原本的 `理化數學詳解與簡答產出規範.md` 與 `exam-answer-key-formatter/SKILL.md`（4 欄表格、【答案】【詳解】、`$LaTeX$` 公式），兩套規則並存、互不取代。

## 一、跟原本「詳解＋簡答」規則的差別

| | 原本（理化／數學詳解＋簡答） | 這份（國文／社會學生詳解本） |
|---|---|---|
| 讀者 | 老師、講義 | **學生**考後自己看 |
| 版面 | Word，4 欄合併表格 | A4 **雙欄**，答案總表在最前面 |
| 每題 | 【答案】【詳解】、共用說明＋逐選項判斷 | 「N 答：(X)」＋一兩行正解＋錯選項各一句 |
| 重點 | 完整判斷每個選項 | **<Key> 可遷移規則**＋色塊關鍵字，越短越好 |

## 二、整本的固定結構（兩科共通）

1. **卷頭**（置中）
   - 第一行：`TZU TZU EDUCATION　茲茲文教`（金棕色、字距拉開）
   - 標題：`<科目><卷別代號>　詳解`，例：`國文H　詳解`、`社會N　詳解`
   - 副標：`<年級>　<學年度學期><段次>　黃金模擬考（<版本>）`
   - 說明（・開頭，2～3 行）：
     - `<Key>是別題也用得到的規則，色塊是關鍵字；✗ 後面是錯選項的破綻。`
     - `範圍：<版本><冊別><課次／章節>。`
     - 社會另加：`先看下面的重點圖表，大部分題目都用得到；題目裡寫「見表②」就回來查。`
2. **答案總表**（圓角框，標題「答案總表　先對答案，再看下面的詳解」）
   - 選擇題：**每列 10 題**，「題號 (答案)」。
   - 非選擇題（國文的國字、注音、注釋）另一張表，每列 5 題，直接寫答案。
3. **（社會）重點圖表**：放在答案總表後、第一題前，見第五節。
4. **正文**：雙欄。大題標題 `一、選擇題　每題2分（共80題）`，下面一條金色線。
5. **頁尾**：中間頁碼，右側 `茲茲文教　TZUTZU　版權所有　請勿外流`；頁面淡浮水印 logo。
6. **頁數**：盡量排成 4 的倍數（A3 對折印小冊子）。社會 N 的成品是 5 頁，**是否一定要補到 4 的倍數，請跟主任確認**；確認前以內容排得下為主，不硬塞空白頁。

## 三、每一題的寫法（兩科共通）

```
N 答：(X)
  [<Key> 可遷移的規則]            ← 有才放，金色底塊
  正解為什麼對，一句話；關鍵字用色塊標出來  ✓
  (A)✗ 破綻　(C)✗ 破綻　(D)✗ 破綻   ← 錯選項一句一個，可以併在同一行
```

- 題目標題只寫「題號＋答：(X)」，**不抄題幹**。題與題之間用虛線分隔。
- 正解說明 **1～2 行**；能用「→」「＝」「↔」就不用整句話：`漢＝察舉 → 魏晉九品官人法 → 隋唐科舉`。
- 錯選項：`(A)✗` 後面只寫破綻，越短越好（`(B)✗ 察舉是漢代`）；說法「反了」就寫 `✗ 反了：…`。正確的選項或結論後面可加 `✓`。
- **色塊**：只標這題真正的關鍵字（題幹的線索、原文的關鍵句、制度名稱），一題 1～3 個。
- **<Key>**：只放「**別題也用得到**」的規則（判斷方法、演變鏈、可套用的句型）。大約全卷 1/4～1/3 的題目有；同一條只在第一次出現時標，後面寫「見第X題」「（見表②）」。只跟這題有關的提示寫成普通一句話。全文**不要出現「口訣」兩個字**。Key 的講法要跟茲茲上課教的一致。
- **能用表格就用表格**：選項之間要比較的（感官對照、字義前後對照、朝代對照）做成小表，表頭用淡金底。
- **照考卷題號順序**，不依單元重排。考卷上的來源學校標記（例如【○○國中】）不寫進詳解。
- 中文和英數之間不空格（`第2題`、`前770年`）。
- **答案一律以答案卷為準**；發現疑義（題幹錯字、選項改過但答案沿用、題號錯）不要自己改，整理成清單給老師。
- 不確定的典故、出處、史實**不要編**。

## 四、國文特別規則

1. **題組**：第一題前加一行 `題組　〈篇名〉（第11～13題）`，下面接灰底框「**整段翻譯**」：
   - 逐句白話、口語；**考到的字詞**用色塊標出來，原文放括號跟在後面，例：`茂盛（鬱鬱）`。
2. **文意、修辭、感官題**：把各選項整理成比較表（例如「選項｜被寫的東西｜拿來比的｜方向」），一眼看出哪個不同。
3. **引原文當證據**：判斷依據用「原文：『……』」引出來，再接 → 結論。
4. **國字・注音・注釋大題**（放在選擇題之後）：
   - 大題開頭一條 <Key>（例：形近字看部首，破音字看詞義）。
   - 字音字形一張表：`題｜答案｜記法`（記法寫部首、詞義、易混的另一個讀音）。
   - 注釋一張表：`題｜解釋｜拆字`（拆字寫單字的意思，例：`肆＝放縱`）。
5. 老師原詳解多半是長段落：保留判斷依據，改寫成上面的短句＋表格；原詳解缺的選項要補齊。

## 五、社會特別規則

1. **重點圖表放最前面**（編號 ①②③④，題目用「（見表②）」「（見圖①）」回查），每張圖表標題旁放一條 <Key>（主線、演變鏈），例：
   - ① 時間軸（朝代順序），<Key> 寫成 `A→B→C` 的鏈。
   - ② 演變表（例：選才方式各階段：時代｜方式｜看什麼｜一句話認出它）。
   - ③ 制度表（制度｜管什麼｜關鍵字）。
   - ④ 對照表（例：兩個朝代的鄰居、外交、宗教並排）。
   - 圖表要**涵蓋大部分題目**；一題用得到的小知識不要放進來。
2. 每題正解多半 **一行**：`線索 → 答案`、`A＝B`，接「（見表②）」。
3. Key 只標**跨好幾題的主線**（例：`秦＝法家，漢＝儒家`、`前770犬戎→平王東遷`），不要每題都標。
4. 選項只寫錯在哪個時代、哪個人、哪個制度，不重述史實。

- [ ] 題號順序跟考卷相同、沒有漏題；題組標題的題號範圍正確。
- [ ] Key 數量大約全卷 1/4～1/3，沒有重複標同一條；全文沒有「口訣」。
- [ ] 國文：每個文言／詩詞題組都有「整段翻譯」；國字注音注釋兩張表都有。
- [ ] 社會：重點圖表編號和題目裡的「見表②」對得上。
- [ ] 卷頭的年級、學年度、段次、版本、範圍正確；頁尾有「版權所有　請勿外流」。
- [ ] 疑義清單（題號＋理由）另外交給老師，詳解照答案卷寫。
