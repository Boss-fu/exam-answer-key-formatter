# 劍潭電腦：安裝茲茲主機背景服務（給電腦擁有者）

這份說明是給「劍潭」這台電腦的擁有者。做完之後，這台電腦會在背景自動提供兩個功能給補習班老師用：

1. **OCR 運算主機**：老師在「匯卷」頁選「劍潭」，考卷就在這台電腦上辨識、切圖、轉成題庫 Excel。
2. **AI 分類橋接**：老師按 AI 補齊（難度、單元、題型、知識點）時，由這台電腦上已登入的 AI 工具處理。老師不需要任何金鑰或連線碼。

特點：**一次安裝，之後開機登入就自動在背景執行，沒有黑視窗，不會被誤關**；掛掉會自動重開。

## 重要說明
- 這台電腦的 **Tailscale 維持你自己的帳號**。不需要登入別人的帳號。老師透過 Tailscale「裝置分享」連進來。
- AI 分類會使用這台電腦上**已登入的 AI 帳號額度**（Claude Code／Codex／Antigravity 擇一）。
- 沒有帳號密碼，保護靠 Tailscale（只有被分享到的人連得上）。不要開 Funnel，不要把埠轉到公開網路。

## 做法（最簡單：交給這台電腦上的 Claude）
1. 把 `skill\jiantan-host-setup\SKILL.md` 放到這台電腦：
   `C:\Users\<你的使用者名稱>\.claude\skills\jiantan-host-setup\SKILL.md`
   （資料夾不存在就自己建立。）
2. 開 Claude Code，對它說：**「幫我設定劍潭主機」**（或輸入 `/jiantan-host-setup`）。
3. 它會一步一步先問你、再安裝：Node／Python 3.11、下載並解密安裝包（**密碼由你自己輸入**，Claude 看不到）、OCR 環境與模型、背景服務、驗證。
4. 它會停下來請你到 Tailscale 後台做兩件事（只有你本人能做）：
   - 開啟 **MagicDNS** 與 **HTTPS Certificates**。
   - 把這台電腦 **Share** 出去（Machines → 這台電腦 → Share），產生分享連結。
5. 它最後會給你一張表：**這台電腦的 Tailscale 名稱、OCR 網址（:8443）、AI 橋接網址（:8790）**。請把這張表傳給管理者。

## 你需要事先準備
- **管理員密碼**（向管理者索取）。安裝包放在公開網站上但已加密，由你自己輸入密碼才打得開；不需要 GitHub 帳號或權限。
- 已登入的 AI 命令列工具至少一個（`claude`、`codex` 或 `agy`）。沒有的話 OCR 還是能用，AI 分類晚點再補。
- 這台電腦要常開機（登入後服務才會跑）。

## 手動做法（不用 Claude 的話）
需要 Node.js LTS、Python 3.11、Tailscale。到 `https://science-qbank.vercel.app/host-download.html` 輸入管理員密碼下載安裝包，解壓縮成 `C:\詳解應用`（不要放 Dropbox／OneDrive），然後：
1. 到 `C:\詳解應用\local-app` 雙擊 **`準備OCR環境.bat`**（建立 OCR 環境與模型）。
2. 雙擊 `C:\詳解應用\local-app` 雙擊 **`安裝主機背景服務.bat`**。
3. 雙擊 **`主機背景服務-狀態.bat`** 確認兩個服務都「執行中」。
4. Tailscale 後台開 MagicDNS＋HTTPS 憑證，並 Share 這台電腦。

## 日常
| 想做的事 | 做法 |
|---|---|
| 看服務是否正常 | 雙擊 `主機背景服務-狀態.bat` |
| 看錯誤紀錄 | `C:\詳解應用\local-app\output\host.log`（另有 `ocr.log`、`ai-bridge.log`） |
| 不想再當主機 | 雙擊 `解除安裝主機背景服務.bat` |

> 這個安裝程式在 Linux 環境測過程式邏輯（啟動、鎖檔、掛掉自動重開、橋接來源檢查）；**Windows 實機是第一次跑**。遇到任何錯誤，請把 `output\host.log` 最後幾十行貼給管理者。
