# 別的 AI 寫詳解，再轉成茲茲 Word

這個流程適合先請 ChatGPT、Gemini 等 AI 依考卷與答案寫內容，再把它的回覆直接轉成茲茲格式的 Word。理化、數學請先確認內容符合國中課綱；國文、社會可另依「學生詳解本規則」調整文字。

## 1. 先貼給寫詳解的 AI

把下列提示詞連同考卷、答案卷一起貼給 AI。答案以答案卷為準；資料不足時請它寫「需人工確認」，不要猜。

```text
請依我提供的考卷與答案卷，寫成可轉 Word 的詳解資料。答案一律以答案卷為準；資訊不足請寫「需人工確認」，不要自行補題意。

只輸出一個 JSON 物件，不要 Markdown、不要程式碼框、不要前言或結語。內容必須是有效 JSON，格式如下：
{
  "summaryLabel": "【單元／作業名稱】頁碼範圍；不清楚就寫需人工確認",
  "sections": [
    {
      "title": "一、計算題",
      "questions": [{
      "no": "1",
      "answer": "A",
      "detail": "正解為什麼對的一句話；若有可遷移的規則才在開頭寫<Key>規則</Key>。",
      "options": [
        {"label": "A", "text": "正確：正確選項為什麼對。"},
        {"label": "B", "text": "錯誤：此選項錯在哪裡。"},
        {"label": "C", "text": "錯誤：此選項錯在哪裡。"},
        {"label": "D", "text": "錯誤：此選項錯在哪裡。"}
      ]
    }]
    }
  ]
}

請務必依原考卷的大題分組，`sections` 的順序、`title`（例如「一、單選題」「二、題組」）與每題 `no` 必須逐字沿用原卷，題號不連續、題組 21～23 也不可自行重編。每題都要有題號、答案、正解一句與所有選項各一句；options 中只能有一個 text 以「正確：」開頭，而且它的 label 必須等於 answer。理化／數學的公式保留為單錢號 LaTeX 文字，例如 $\\sqrt{2}$；**任何 `$...$` 內一律不得有中文，連舊式 `F_{甲}` 程式標記也禁止。** 中文上下標一律寫在公式外：`F<sub>甲</sub>`、`v<sub>平均</sub>`、`x<sup>最大</sup>`，轉 Word 工具會改為原生上下標，不能 Toggle TeX。輸出前自我檢查：任何 `$...$` 內沒有中文、題號照原卷、所有原卷大題均已在 `sections` 保留；只用國中課綱的概念與講法。
```

例如第 1 題可以長這樣（舊的頂層 `questions` 格式仍相容；新資料請優先用上面的 `sections`；實際使用時仍要把整份考卷所有題目放進同一個 JSON）：

```json
{
  "summaryLabel": "【光的折射】p.90-92",
  "questions": [
    {
      "no": 1,
      "answer": "A",
      "detail": "光穿過不同介質，傳播速度改變時會發生折射。",
      "options": [
        {"label": "A", "text": "正確：透鏡利用光的折射成像。"},
        {"label": "B", "text": "錯誤：平面鏡成像屬於反射。"},
        {"label": "C", "text": "錯誤：影子的形成主要是光沿直線前進。"},
        {"label": "D", "text": "錯誤：月亮本身不會發光，只是反射日光。"}
      ]
    }
  ]
}
```

## 2. 拿到回覆後轉 Word

1. 將 AI 的完整回覆存成 UTF-8 文字檔，例如 `我的詳解.txt`；即使回覆前後有客套話或放在 JSON 程式碼框，也可以直接存。
2. 在專案根目錄執行：

```bash
node tools/詳解轉word.js 我的詳解.txt 我的詳解.docx
```

工具會從回覆中找出含有 `questions` 或 `sections` 的 JSON，先核對每題答案是否和唯一的「正確：」選項一致，再沿用既有 `code/build_from_json.js` 的茲茲 Word 版型輸出。若顯示「轉換失敗」，請依錯誤訊息請 AI 修正 JSON 後重跑。

## 3. 在 Codex App 怎麼說

上傳或貼上 AI 寫好的詳解後，直接說：

> 照 `docs/詳解_別的AI寫內容轉Word.md`，把這份詳解做成 Word。

若同時提供考卷與答案卷，也可以補一句「請先核對答案卷；有疑義列出來，不要自行改答案」。
