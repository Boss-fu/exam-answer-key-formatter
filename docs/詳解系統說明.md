# 茲茲文教｜詳解系統（理化詳解產生器）說明

> 網址：<https://tzutzu-ocr.vercel.app/answer.html>
> 本文件分三篇：**使用者篇**（老師、主管）、**管理員篇**（帳號、邀請碼、額度）、**開發者篇**（架構、API、部署、修改規範）。
> 每次修改系統都要同步更新本文件與頁面的更新公告（見〈修改規範〉）。

## 一、使用者篇

### 第一次使用（只需一次）
1. **安裝 Tailscale**：到 <https://tailscale.com/download> 下載安裝，用自己的 Google／Microsoft／Apple 帳號登入。
2. **接受分享**：打開管理員傳給你的 Tailscale 邀請連結，按 Accept。你只會看到「公司電腦」這一台。
3. **取得邀請碼**：管理員會給你一個邀請連結（`…/answer.html?invite=XXXX-XXXX`）或 8 碼邀請碼。
4. 一律開管理員提供的 **Vercel 邀請網址**；iPhone／iPad 在確認公司電腦可連線後會自動切換到直連頁，保留邀請碼。請先開啟 Tailscale；Chrome 若詢問「區域網路存取」請按**允許**。

### 每次使用
1. 確認頁首顯示 **● 已連線**、今日還有剩餘份數。
2. 拖放或點選考卷：PDF、Word（.docx）、PNG、JPG，一次一份，PDF 最多 12 頁。**請上傳空白題目卷**（避免學生個資送到 AI）。
3. （選填）**官方答案**：每題以空白或逗號分隔，多選字母連寫，例如 `D C B CE A`。有填時 AI 以官方答案為準撰寫詳解，速度較快。
4. （選填）**講義標題**、**單元**：有填才會出現在 Word 最上方；沒填就只有簡答列與詳解。
5. 按 **產生詳解**，約 1～5 分鐘，請勿關閉頁面。
6. 在 **檢查與修改** 畫面：被標記的題目排在最前面，可修改答案、詳解、各選項說明；修改自動保存在這台裝置。
7. 按 **下載 Word**。公式為 `$…$` 純文字，在 Word 用 MathType 的 **Toggle TeX**（Alt+\）一次轉換。

### 詳解的寫法規則
- **一般選擇題**：每個選項寫「正確／錯誤：說明」。
- **否定問法題**（何者錯誤、何者不正確…）：「正確／錯誤」判斷的是**該選項敘述本身**，答案是標「錯誤」的選項。
- **計算題**：只寫一段統一詳解，不逐一列出選項。
- **Word 格式**：全部題目在同一個表格連續排列（跨頁由 Word 自然分頁）；段落不貼齊格線、不自動調整右側縮排、單行間距。

### 常見問題
| 狀況 | 處理 |
|---|---|
| 顯示「未連線」 | 公司電腦是否開機？你的 Tailscale 是否已連線？Chrome 問「區域網路存取」是否按了允許（若曾按封鎖：網址列左側圖示 → 網站設定 → 區域網路存取 → 允許）？ |
| 想確認網路是否通 | 直接打開 `https://ljm2222.tail3d3c18.ts.net:8443/api/health`，看到 `{"ok":true…` 代表網路正常，問題在瀏覽器或頁面。 |
| iPhone／iPad | 一律使用 Vercel 網址，先開啟 Tailscale；圖片探測成功會自動切換到直連頁。公司電腦未開或 Tailscale 未連線時不跳轉，請確認後按「重新連線」，也可按「改用直連網址開啟」。 |
| 「目前已有一份考卷在處理中」 | 同一時間只處理 1 份，幾分鐘後再試。 |
| 「今天的額度已用完」 | 每天全站共 10 份（台北時間午夜重置），急用請聯絡管理員。 |
| 「此邀請碼已被管理員停用」 | 請向管理員索取新的邀請碼。 |
| 標記「AI 意見不一致」 | Claude 與 ChatGPT 答案不同且重算後仍不一致，請人工判斷後修改。 |

## 二、管理員篇

### 設定管理員密碼（第一次，或要更換時）
在**公司電腦**開 PowerShell 執行（輸入時畫面不顯示字元是正常的）：
```powershell
cd C:\詳解應用
node local-app/set-admin-password.js
```
密碼只以雜湊存在 `C:\詳解應用\local-app\output\auth\`，不會進 GitHub。**請勿把密碼貼到任何聊天或文件中。**

### 邀請碼管理
1. 在詳解頁面切到「管理員」分頁，輸入密碼登入。
2. 「邀請碼管理」區輸入老師名稱 → **建立邀請碼**。明碼與邀請連結**只顯示這一次**，請立即複製給老師。
建立後主要顯示 Vercel 邀請連結，**一律給所有人 Vercel 網址**。iPhone 會自動切換，通常不需要用小字「備用：直連連結」；兩者各有複製按鈕。
3. 列表可看到每組碼的老師名稱、末 4 碼、建立時間、最後使用、產出份數；可隨時**停用／重新啟用**（停用後該老師立即被登出）。
4. 老師仍需 Tailscale 分享公司電腦才能連線（Tailscale 管理頁 → ljm2222 → ⋯ → Share）。

### 額度與用量
- 全站每天 **10 份**（環境變數 `ANSWER_KEY_DAILY_LIMIT` 可調），同時只處理 **1 份**；呼叫 AI 前才扣額度。
- 每份用量記錄在 `C:\詳解應用\local-app\output\usage\YYYY-MM-DD.json`：誰、檔名、頁數、秒數、Claude／ChatGPT tokens、爭議題數。
- 參考實測（4 頁 28 題）：約 78 秒；Claude 輸出約 8.7k tokens（輸入多為快取）、ChatGPT 約 25k tokens。皆走訂閱額度，不按 token 計費。

## 三、開發者篇

### 架構
```
瀏覽器 ── tzutzu-ocr.vercel.app/answer.html（Vercel，只有靜態前端 local-app/public/）
   │  （Tailscale 私有網路，HTTPS）
   ▼
公司電腦 ljm2222  https://ljm2222.tail3d3c18.ts.net:8443 ──tailscale serve──▶ 127.0.0.1:8787
   C:\詳解應用（GitHub main 的乾淨 clone）  node local-app/server.js
   ├─ Claude Code CLI（主筆，寫完整詳解）
   └─ Codex CLI / ChatGPT（唯讀沙箱，只回答案交叉核對）
```
- 前端與後端分開部署：**推 GitHub main → 公司電腦 5 分鐘內自動更新**；**前端要另外執行 Vercel 發布**。
- 不開公開入口（不使用 Tailscale Funnel）；登入只控管「誰能用詳解系統」。

### 主要檔案
| 檔案 | 作用 |
|---|---|
| `local-app/public/answer.html` | 詳解系統頁面（上傳、檢查與修改、登入、邀請碼管理、使用說明） |
| `local-app/public/answer-rules.js` | 答案一致性規則（多選、否定題、計算題），前後端共用 |
| `local-app/public/answer-changelog.json` | 詳解系統的更新公告內容 |
| `local-app/answer-key.js` | 檔案分流：PDF 一律轉圖（pdftoppm 200dpi，≤12 頁）、docx/txt 走文字、圖片直接看圖 |
| `local-app/ensemble.js` | 多 AI 合作：Claude 寫詳解＋ChatGPT 對答案；爭議題只交回 Claude 重算；Gemini 介面預設關閉（`ENSEMBLE_GEMINI=1`） |
| `local-app/engine.js` | Claude／Codex 呼叫與 prompt（含計算題、否定題規則） |
| `local-app/auth.js`、`set-admin-password.js` | 管理員密碼、邀請碼、session |
| `local-app/quota.js`、`usage.js` | 每日額度、同時處理數、用量紀錄 |
| `code/render.js`、`code/lib3.js` | Word 產生（單一連續表格、段落設定、選填標題／單元） |
| `local-app/auto-update.ps1` | 公司電腦每 5 分鐘自動更新與重開服務 |
| `local-app/deploy-vercel.sh` | 只把 `local-app/public` 發布到 Vercel |

### API（公司電腦）
| 方法與路徑 | 需登入 | 說明 |
|---|---|---|
| `GET /answer.html`、`GET /answer-changelog.json` | 否 | 公司電腦直連頁與 JSON 公告，只開放明確檔名 |
| `GET /answer-tutorial.mp4` | 否 | video/mp4，支援單一 bytes Range（206；無效範圍 416） |
| `GET /api/health` | 否 | 版本、能力清單 |
| `POST /api/auth/admin` `{password}` | 否 | 管理員登入 → token |
| `POST /api/auth/invite` `{code}` | 否 | 邀請碼登入 → token |
| `GET /api/auth/me`、`POST /api/auth/logout` | 是 | 目前身分／登出 |
| `GET /api/admin/invites`、`POST /api/admin/invites` `{label}` | 管理員 | 列表／建立（回傳一次明碼） |
| `POST /api/admin/invites/disable`、`/enable` `{id}` | 管理員 | 停用／啟用 |
| `POST /api/answer-key` `{filename, dataBase64, officialAnswers?}` | 是 | 產生詳解（扣額度） |
| `GET /api/answer-key/quota` | 是 | `{limit, used, remaining, busy, date, tokens}` |
| `POST /api/answer-key/render` `{data, filename}` | 是 | 產生 Word（含 docTitle、unitName） |

token 以 `Authorization: Bearer` 傳送；登入嘗試每 IP 每分鐘 10 次。OCR 系統原有 API（`/api/render`、`/api/generate` 等）不需登入、行為不變。

### 本機開發與驗證
```powershell
git clone https://github.com/Boss-fu/exam-answer-key-formatter.git C:\dev\exam-answer-key-formatter
cd C:\dev\exam-answer-key-formatter
npm install
node --test (Get-ChildItem local-app\test -File | Where-Object Name -Match '\.test\.c?js$').FullName
$env:PORT = '8790'; node local-app/server.js   # 測試用埠，不影響正式 8787
```
- 真 AI 驗證：Claude 需 `CLAUDE_BIN` 指向 `claude.exe`、ChatGPT 需 `CODEX_BIN` 指向 Codex App 內附的 `codex.exe`（`start.bat` 會自動尋找）。
- 測試頁從 `localhost` 開啟時連不到公司電腦是正常的（CORS 白名單只放行正式網址）。

### 部署流程
1. 在開發用 clone 修改、測試 → `git push origin main`。
2. 公司電腦 5 分鐘內自動更新（看 `C:\詳解應用\local-app\output\auto-update.log`）。
3. 前端有改時，在公司電腦以 Git Bash 執行 `bash local-app/deploy-vercel.sh`（Vercel CLI 已登入 boss-fu）。發布前需經負責人同意。

### 修改規範（每次修改都要做）
1. **更新公告**：在 `local-app/public/answer-changelog.json` 最前面加一則（version 用 `YYYY.MM.DD.N`，白話寫標題、說明、要點）。
2. **更新本文件**對應段落。
3. 跑全部測試；`no-garbled-text` 測試會擋下被錯誤編碼成 `???` 的中文。
4. 程式、公告、文件放在同一個 commit；commit 結尾加協作署名。

### 已知坑
- Safari 的跨網站／隱私保護可能擋下 Vercel → 公司電腦的 fetch。一律給 Vercel 網址：跨來源時用 `new Image()` 載入公司 `/logo.png?probe=時間戳`（6 秒逾時）；iOS／iPadOS（含 MacIntel 且 maxTouchPoints > 1 的 iPad，亦涵蓋 iOS Chrome／Firefox）圖片成功就立即 `location.replace` 到直連頁。其他瀏覽器照常 fetch `/api/health`，僅網路失敗且圖片成功才切換；兩者都失敗則保留說明、重新連線及手動直連按鈕。完整保留 query（含 invite）與 hash，切換前顯示提示；公司同源頁不探測也不自動跳轉，sessionStorage 以 try/catch 記錄 30 秒內最多自動跳一次，避免迴圈。兩來源登入與草稿分開，切換後需重新登入（有 invite 則自動登入）。
- Windows PowerShell 5.1 讀無 BOM 的 UTF-8 腳本會亂碼 → `.ps1` 檔一律存成 UTF-8 **有 BOM**。
- AI 工具寫檔時偶爾把中文寫成 `???` → 已有測試防護，交付前務必跑測試。
- Node 不能直接 spawn npm 的 `.cmd` 包裝 → 用 `CLAUDE_BIN`／`CODEX_BIN` 指向實際 exe。
- 不要在 `C:\詳解應用` 直接改檔（會讓自動更新停住）；所有修改走 GitHub。
- 前端要相容舊版 iPhone Safari（iOS 15）：不要直接用 `AbortSignal.timeout`，改用頁面內的 `timeoutSignal(ms)`；`browser-compat` 測試會檢查。
