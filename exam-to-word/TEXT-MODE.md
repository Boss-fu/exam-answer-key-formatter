# 純文字快速模式（不裁圖，速度優先）

這是 `exam-to-word` 的「快速版」：**只重打文字與表格，不裁任何圖**。圖的位置改用一行
`〔含圖：<簡短說明>〕` 佔位，讓使用者之後自己在題庫系統手動框選截圖貼上。
目標是一份考卷 3–5 分鐘內產出可下載的乾淨 Word。

## 和完整模式的差別

| 項目 | 完整模式（SKILL.md） | 本快速模式 |
|---|---|---|
| 題目文字 | 逐字重打 | 逐字重打（相同） |
| 表格 | 重打成 Word 表格 | 重打成 Word 表格（相同） |
| 圖片 | 裁切、去筆跡、inline 插入 | **不裁**，改放 `note("說明")` 佔位 |
| 答案／詳解 | 不產（本來就不產） | 不產 |
| 速度 | 慢（每張圖要來回校對） | 快（讀一次卷、只打字） |

## 流程

1. **讀卷抓文字**：把來源 PDF/圖片讀過一遍（`imgtools.prep` 轉頁或直接看圖），
   逐題、逐選項、逐表格把印刷文字抄下來。忽略學生手寫作答與老師批改筆跡。
   **不要**做 `view` 找座標、**不要** `save` 裁圖 —— 這一步整段跳過。
2. **寫內容腳本**（照 `references/example_build.py` 的形式，但）：
   - 題目 `q(...)`、表格 `tbl(...)`、大題 `p_section(...)`、題組 `p_intro(...)` 照常。
   - **每一處原本有圖的地方**，用 `note("<簡短說明>")` 取代 `p_image(...)`。
     說明只寫「這裡是什麼圖」，例如 `note("天平圖(一)未歸零、圖(二)左盤蘋果右盤300g砝碼")`，
     方便使用者知道要框選哪張圖貼上；不要重覆整段題幹。
   - 若圖上有可讀的關鍵數據點/座標（例：折線圖交點、散點座標），可簡短寫進 `note(...)` 幫助命題者。
   - **不要**輸出答案，也不要標正解。
3. **組檔**：`finish(C, "<outputDir 內的 .docx>", repl=[...])`，橫幅 `repl` 照 SKILL.md 的卷頭資訊填。
4. **驗證**：`python3 -c "import docx; docx.Document('<out>')"` 能開即可（本模式不需 render 預覽，省時間）。

## 交付

- Word 存到指定 `outputDir`。
- 「需人工確認清單」只需列：推定的橫幅/科目/冊別、原卷疑似錯字、看不清的文字。
  圖片不用列（本來就交給使用者自己截圖）。
- 每題末尾的 `〔含圖：…〕` 就是使用者貼截圖的定位點。
