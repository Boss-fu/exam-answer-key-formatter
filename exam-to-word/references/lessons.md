## 1. 座標判讀

- 縮小的整頁或窄欄圖裡，用目測比例估 x 座標曾經連續錯好幾次（誤差上百像素）。**只讀 view() 畫上去的格線數字**；需要精確時縮小範圍、放大 scale 再看一次。
- 讀到的 view 座標要換算：原圖座標 = box 左上角 + 檢視座標 ÷ scale。
- 要精確座標（重畫線、找分隔線）時，直接分析像素：
  ```python
  d = a < 128
  np.where(d[y, x1:x2])[0] + x1      # 某一列的黑點 x
  (d[y1:y2, x1:x2]).sum(0)           # 每欄黑點數 → 找直線（格線、分隔線）
  ```
- 找某個小物件（圖示）的外框：`cv2.connectedComponentsWithStats` 取最大連通塊。

## 2. 裁切常見缺陷

| 症狀 | 處理 |
|---|---|
| 圖右緣有一條直線 | 雙欄考卷中間的分隔線。x2 往內縮到線的左邊（用每欄黑點數找線的位置） |
| 圖上緣有半行字 | 題目文字殘邊。y1 往下，或該區 rect 塗白（圖本身若和文字同高就只塗文字的 x 範圍） |
| 座標軸數字、單位、「時間(秒)」被切 | y2 往下；下緣緊接選項文字時，量每列黑點找出兩者之間的空白列 |
| 標籤（如 B、甲）被切掉 | x1 往外；注意外面可能有學生寫的答案字母 |
| 自動去白邊後尺寸異常縮小 | 原本是分隔線或雜點撐大了邊界，這通常是好事，但要確認沒有切到真的內容 |

## 3. 去筆跡技巧

- 黑白（1-bit）掃描的筆跡和印刷一樣黑，只能靠位置與形狀區分。彩色掃描的紅筆可用顏色篩，但仍要逐張確認。
- `smart()` 的原理：在擦除帶上，若某點沿水平、垂直或另一條對角方向兩側都是黑的，就視為印刷線交叉點而保留。適合細的直線筆跡；很粗的塗鴉效果差，改用 rect＋重畫。
- `cv2.inpaint` 對黑白線稿效果不好（會糊成一團），不要用。
- 手寫筆跡通常不是完美直線：用 `hough()` 找到的多段線段接成折線，寬度 t 取 7～11。
- 圖裡的圈選記號（學生把數據點圈起來）：先把小範圍塗白，再依量到的座標重畫格線（實線或虛線）與資料線。
- 被塗掉的選項標籤，例如 (C)：先 rect 清空再 `text()` 重打，字級約等於旁邊標籤高度的 1.2 倍，重打後放大檢查。
- 學生寫的答案字母多在題號左側，裁切時避開；老師的紅筆分數在卷頭，不會進到圖裡。
- 標籤字被圈（例如「乙」被大圈框住）：清掉圈線後，從同一張卷的其他圖找同一個字（同字型）複製貼上。

## 4. 範本內部結構

- 範本是茲茲的課前考 docx：開頭第一段是橫幅（群組圖形，內含「國七生物」「第一冊」「10」「Ch1(全)」「【112.百齡】」等文字框，每個文字在 mc:Choice 與 mc:Fallback 各出現一次，替換要全部取代）。buildlib 保留第一段到 paraId 54D94374 之前的內容，其餘換成新內文。
- 選擇題自動編號用 numId 18（格式「1.(　　)」），定位點在 3000／5280／7560 dxa；字型 華康中圓體(P)，大題標題用 華康中圓體＋外框。
- pPr 子元素順序有 schema 限制：numPr → tabs → adjustRightInd → snapToGrid → spacing → ind → jc。順序錯了 validate 會報錯。
- 儲存格 tcPr 順序：tcW → gridSpan → tcBorders → vAlign。
- 頁面：A4，邊界 567 dxa，內文寬 10772 dxa（7.48 吋）。

## 5. 其他

- 題號範圍（如「2-5 題」）原卷只有粗體 → 用 `^…^`，不要用 `*…*`（那是粗體加底線）。
- 行內小圖（例如題幹裡的省道標誌）用 `§name:高度吋§`，高度約 0.25～0.3 吋可和文字同高。
- 選項用定位點但字太長時會溢到下一個定位點而錯位：改成兩行，每行兩個選項，中間用全形空格。
- 交付時如果產出檔沿用或修改使用者既有的檔案，要主動說明。
