# 考卷轉茲茲 Word 格式

把一份（或多份）考卷掃描檔變成可編輯、套用茲茲範本的 .docx。成品要像老師重新打字排版過的考卷：文字可編修、表格是 Word 表格、圖片乾淨、題號自動編號。

交付物永遠是：**Word 檔 ＋ 一段簡短的「需人工確認清單」**。筆跡清除不可能每次完美，把殘留與不確定之處老實列出來，比假裝完美更有用。

## 檔案配置

- `scripts/buildlib.py`：Word 組版（段落、題目、表格、圖片、橫幅替換）。範本 `assets/template.docx` 已內建。
- `scripts/imgtools.py`：掃描頁處理（轉圖、座標檢視圖、裁切、去筆跡、字形修補、聯絡表）。
- `scripts/render.py`：docx → PDF → 預覽圖，用來校對。
- `references/example_build.py`：完整的內容腳本範例（35 題、含圖表、題組、行內小圖、下標）。**寫新考卷的內容腳本前先讀它。**
- `references/lessons.md`：踩過的坑與細節規則（座標判讀、去筆跡技巧、範本內部結構）。遇到圖片處理或排版問題時讀。

開工時把 scripts 複製到工作目錄，每份考卷一個工作目錄：

```bash
SKILL=/mnt/skills/user/exam-to-word            # 技能實際安裝路徑，依環境而定
export EXAM_WORK=/home/claude/exam/<簡稱>     # 例如 /home/claude/exam/yangming8
export EXAM_TEMPLATE=$SKILL/assets/template.docx
mkdir -p $EXAM_WORK && cp $SKILL/scripts/*.py $EXAM_WORK/
```

## 流程

### 1. 辨識考卷資訊

從卷頭讀出學年度、學期、年級、科目、學校、第幾次段考。決定：

- 輸出檔名：`113上-國八自然-一段-陽明國中.docx`（學年＋學期／國X科目／段次／學校）
- 橫幅文字：範本橫幅原文是「國七生物」「第一冊」「10　Ch1(全)【112.百齡】」，用 `finish()` 的 `repl` 替換，例如
  `[('<w:t>國七生物</w:t>','<w:t>國八理化</w:t>'), ('第一冊','第三冊'), ('<w:t>10</w:t>','<w:t>一段</w:t>'), ('Ch1(全)','Ch1~2'), ('【112.百齡】','【113.陽明】')]`
- 冊別：七上第一冊、七下第二冊、八上第三冊、八下第四冊、九上第五冊、九下第六冊。
- 科目標籤沿用使用者之前的選擇：七年級「國七生物」、八年級「國八理化」、九年級「國九自然」。拿不準就照推定的做，並在交付時說明。

筆跡很多時（整頁劃線、圖被圈滿），先問一句有沒有空白原卷；有的話品質與速度都好很多。第三方 OCR 轉出的 docx（如試卷寶）錯字多、圖解析度低，不如直接用原掃描檔。

### 2. 轉頁面、看版面

```python
from imgtools import *
prep('/mnt/user-data/uploads/考卷.pdf')        # → pages/p-1.png…（300dpi 灰階）
view(1, (0,0,W//2+100,H), 'p1L', scale=0.3)      # 左半頁（雙欄考卷分左右看）
```

用 view 圖讀題目文字與圖的大致位置。**座標只讀格線上的數字標籤，絕不用「看起來大概在圖的幾分之幾」去推算**——這是最常出錯的地方（見 lessons.md）。

### 3. 打字（內容腳本）

照 `references/example_build.py` 的形式寫一支內容腳本。重點規則：

- 文字**照原卷**，不潤飾、不改題號引用。原卷的錯字或疑似錯誤（例如題幹寫「俠客」但前文是媽媽、選項印 35% 而應為 35‰）一律保留原文，列入確認清單。辨識不確定的字也列入。
- 行內標記：`_人名/地名_` 底線；`*錯誤*`、`*不包含*` 粗體底線；`^2-5^` 粗體（題號範圍）；`~甲~` 下標；`§icon:0.28§` 行內小圖（名稱:高度吋）；`\n` 換行；`\t` 定位點。
- `q(題幹, [選項…])`：自動編號 1.(　　)；選項短就用定位點對齊，長就自動換行。題幹與選項之間要夾圖或表時，`q(題幹, [])` → 圖／表 → `opts_para("(A)…　(B)…\n(C)…　(D)…")`。
- 題組引言用 `p_intro("1. …")` 或 `p_intro("◎ …請回答^29～31^題：")`；大題用 `p_section("一、單選題【每題2分，共50分】")`。
- 表格用 `tbl(rows, 欄寬dxa)` 重打（整頁寬約 10772 dxa）；合併儲存格寫 `("文字", 跨欄數)`；左上角斜線格寫 `"╲"`。
- 題組小題原卷若標 (26)、(27)，範本會自動連號成 26.(　)，所以「承(32)題」這類引用不用改。

### 4. 裁圖與清筆跡

每張圖的迴圈：**寬鬆 view → 讀座標 → save 裁切 → 放進 sheet 聯絡表檢查 → 修正**，直到沒有切到標籤、沒帶進題目文字或欄位分隔線。

- 裁切時的常見缺陷：座標軸標籤／單位被切（往下多留）、上方題目文字的殘邊（往下縮或 rect 塗白）、雙欄考卷中間的分隔線（x 往內縮；可用 `edge_lines()` 檢查）。
- 清筆跡由簡到繁：
  1. 筆跡在空白處 → `rect()` 塗白。
  2. 筆跡劃過印刷內容 → 用 `hough()` 找出線段端點，`smart()` 沿線擦除（會保留交叉的印刷線與字）。
  3. 字被劃破 → `restore()` 從卷面別處找同一個字貼回。
  4. 圖線被蓋住 → 量出原線座標（取乾淨段的像素中心），塗白後用 `cv2.line` 重畫；虛線照原間距畫點。
  5. 四個選項圖版面相同時 → `offset()` 算位移，從乾淨的那張複製對應區塊。
  6. 標籤被塗掉 → `text()` 重打（英數用 FreeSerif，中文用 Noto）。
- 能重打的就不要截圖：表格、照片式或看不清的標示（重建成表格並標註「重建」）。

### 5. 組版、驗證、校對

```bash
cd $EXAM_WORK && python3 build.py
python3 /mnt/skills/public/docx/scripts/office/validate.py <輸出.docx>
python3 render.py <輸出.docx>        # 看 pages_*.jpg
```

校對時看：圖是否太大或太小（一般 2～5 吋寬）、選項定位點是否溢出（溢出就改用全形空格加換行）、有沒有殘邊與雜點。預覽用 LibreOffice，浮動圖片的分頁可能和 Word 不同，交付時提醒一句即可。

### 6. 交付

- 存到 `/mnt/user-data/outputs/`，**一定要呼叫 present_files**，不然使用者拿不到檔案，也看不到檔案卡。
- 回覆簡短：做了什麼（題數、重打的表格、清過筆跡的圖）＋「需人工確認清單」（重建的內容、保留的原文疑點、清不乾淨的殘留、推定的橫幅／科目）。
- 使用者要答案時，選擇題答案用純文字 code block、每 5 題一行（例：`1~5　ACACD`），不要用表格。答案是自己算的就說明，不確定的題目標出來。

## 批量處理

使用者一次丟多份時：逐份依上面流程處理，**每完成一份就先交付那一份**（present_files），再做下一份；每份用獨立的 `EXAM_WORK` 目錄與 build 目錄，避免圖片與暫存混用。單輪操作次數用完時，明確回報「已完成哪幾份、目前做到哪份的哪一步、下一步是什麼」，使用者回「繼續」就接著做。
