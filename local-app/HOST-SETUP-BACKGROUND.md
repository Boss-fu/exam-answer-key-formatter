# 主機背景服務（Windows）— 一次安裝，OCR 主機＋AI 橋接＋HTTPS 全部在背景跑

**沒有黑視窗**：登入後自動在背景執行，右下角（可能收在「^」隱藏圖示裡）有一個紅色「茲」小圖示，像 Tailscale 一樣，點它可叫出狀態視窗；掛掉自動重開；有新版（資料夾是 git clone 時）自動更新。

## 右下角小圖示怎麼用
- 紅色「茲」＋綠點＝運作中；灰色＋紅點＝有服務沒在跑（小工具會自動嘗試重開）。
- **雙擊圖示**（或右鍵 →「開啟狀態視窗」）：看兩個服務狀態、Tailscale 名稱、網址、最近紀錄。
- 右鍵選單：複製 OCR／AI 橋接網址、重新啟動服務、開啟紀錄資料夾。
- **結束（停止主機）**：要按確認才會停止，不會因為誤點關掉；結束後 5 分鐘看門狗也不會自己叫回來，要用「開始功能表 → 茲茲主機」才會再啟動。
- 圖示不見了：點工作列右下角「^」看隱藏圖示，可以把它拖出來固定；或到開始功能表找「茲茲主機」。

## 這個背景程式包含什麼
| 功能 | 說明 |
|---|---|
| OCR 主機 | `server.js`，埠 8787，並自動設好 `https://<主機名稱>:8443`（Tailscale 私有 HTTPS） |
| AI 橋接 | `ai-bridge.cjs`，埠 8790，自動設好 `https://<主機名稱>:8790`；**老師免輸入連線碼**，只接受題庫網頁（science-qbank.vercel.app）來源 |
| 看門狗 | `host-supervisor.js`：兩個服務掛掉會自動重開 |
| 系統匣小工具 | `host-tray.ps1`（經 `host-tray-launcher.vbs` 隱藏啟動，沒有任何視窗）：右下角圖示、狀態視窗、複製網址、重新啟動、開啟紀錄、結束；也負責確認主機服務還在跑 |

## 安裝（在主機電腦做一次）
前置：已安裝 **Node.js LTS** 和 **Tailscale（已登入）**；若要 AI 橋接，裝好並登入其中一個 AI 命令列工具（Claude Code／Codex／agy）。

1. 在這個資料夾雙擊 **`安裝主機背景服務.bat`**。
2. 看到「OCR 主機（8787）：執行中」「AI 橋接（8790）：執行中」，並印出兩個 `https://…` 網址，就完成了。
3. 之後不用再開任何視窗。檢查用 **`主機背景服務-狀態.bat`**，不想用了用 **`解除安裝主機背景服務.bat`**（會還原舊的「詳解本機應用 自動更新」排程）。

> 這台電腦原本若用 `start.bat`＋「詳解本機應用 自動更新」，安裝時會自動停用舊排程並關掉舊視窗，避免兩份搶同一個埠。

## 建議的上線順序
1. **先在「分部電腦」試**（比較不影響大家），確認：
   - 匯卷頁「OCR 運算主機」選「分部電腦」→「測試連線」顯示已連線。
   - 關掉所有視窗、重開機登入後，主機仍會自動起來。
   - AI 分類（難度、單元、知識點）能跑。
2. 沒問題再換「公司電腦」。
3. 最後裝到**主管電腦**，當主要主機（見下）。

## 主管電腦（用主管自己的 Tailscale，不登入你的帳號）
1. 在主管電腦照上面「安裝」做一次（主管的 Tailscale 維持他自己的帳號）。
2. 主管 Tailscale 後台（login.tailscale.com/admin/dns）：開啟 **MagicDNS** 與 **HTTPS 憑證**。
3. 主管在後台把這台電腦**分享**出去（Machines → 這台電腦 → Share），產生分享連結。
4. 老師用自己的 Tailscale 帳號開啟分享連結，按 Accept（做法和接受公司電腦相同）。
5. 把主管電腦的 OCR 網址（`https://<名稱>.ts.net:8443`）貼給網站：匯卷頁選「主管電腦」，第一次會請你輸入這個網址。

## 多人同時使用（同時連線）
- **同時連線**：很多位老師可以同時連到同一台主機（Tailscale 沒有人數限制的設計，但每位老師要各自接受分享）。
- **同時處理**：預設 OCR／切圖與 AI 分類都是「一次處理一份、其餘排隊」，因為 OCR 很吃記憶體。主機夠強可以調高：在 `local-app` 建立 `host-config.json`：
  ```json
  {"ocrConcurrency": 2, "aiConcurrency": 3}
  ```
  存檔後在圖示右鍵「重新啟動服務」。建議 OCR 最多 2（每份約需數 GB 記憶體），AI 分類看 AI 帳號的額度。
- 排隊時老師的網頁會顯示「主機正在處理其他考卷，排隊中」。

## 注意
- **只用 Tailscale 私有網路**，不要用 `tailscale funnel`，不要把 8787／8790 轉發到公開網際網路。
- AI 橋接用的是這台電腦上已登入的 AI 工具，多位老師同時用會共用那個帳號的額度；一次只處理一題。
- 沒有帳號密碼，保護靠 Tailscale（只有被分享到的人連得上）＋網頁來源白名單。
- 紀錄：`local-app\output\host.log`（總管）、`ocr.log`、`ai-bridge.log`、`tray.log`（小工具）。
- 這個安裝腳本在 Linux 測試環境驗證過程式本身（起動、鎖檔、掛掉重開、橋接來源檢查），**工作排程與 Windows 行為尚未在實機驗證**，請先在分部電腦試。
