OCR WORKSPACE

考卷 OCR 工作台

掃描考卷在自己的主機辨識，轉成可校對的乾淨 Word；需要「看懂題目」的步驟才會用 AI，並清楚標示。

第 1–3 步全本地・零 token・考卷不出主機第 4–5 步會呼叫 AI 判斷題意

開啟 Mac 網站服務

作業模組

一次處理一個步驟；切換模組不會清掉已上傳的資料

1

本地轉檔：掃描卷 → 乾淨 Word本地・0 token

上傳掃描 PDF／圖片，主機用 PP-OCRv5（ONNX／CPU）直接辨識：自動切雙欄、裁圖、標記低信心行，輸出乾淨文字草稿 Word。不呼叫任何外部 AI，考卷不離開主機。

辨識後
  • 文字出現在下方編輯框；公式、表格請對照原卷校對，標 ⚠需確認 的行先看。
  • 附圖已自動裁成 *_fig*.png；要更精準請用第 2 步「框選截圖」。
  • 數位 PDF（有文字層）準確度近乎完美；模糊的掃描卷當打字初稿最快。
主機尚未安裝 OCR？

此功能需主機先安裝 Python 套件與 OCR 模型；未安裝時會提示，不影響其他模組。在主機的專案資料夾執行：

pip install -r ocr/requirements.txt
python3 ocr/get_models.py
2

框選截圖（題目附圖）本地

載入掃描 PDF，在瀏覽器裡渲染頁面、拖框截圖；可建立單題圖與題組共用圖，原始檔不會上傳到任何外部服務。

操作方式在頁面上拖曳框出區域，輸入題號後存成 Q題號.png；題組共用圖在題號前加 g（例如 g24）。可一次打包 ZIP 下載，全程在瀏覽器本機執行。
3

OCR 預檢與品質覆核本地

以本機 OCR 建立印刷文字、題號錨點與題目候選區。手寫作答與批改不納入資料；系統依辨識信心把需要覆核的題目排進佇列。

覆核重點核對頁數、題號順序、題目影像與文字。可直接修改單題文字後確認；只更新該題，不會整卷重新辨識。
4

結構化重建與資料匯出會用 AI

把試卷影像整理成可編輯的 Word 與 23 欄題庫 CSV。這一步要「看懂題目」判斷題型／單元，會呼叫 AI；只需要乾淨 Word 請用第 1 步「本地轉檔」。

圖的位置會先留〔含圖〕，可再把第 2 步截好的圖貼回該題下方。

已有 23 欄 CSV？可直接產生 Word，不重新辨識、不呼叫 AI。
5

詳解生成與答案校驗會用 AI

匯入題目文字、文件或照片，逐題產生詳解；可對照官方答案檢查命中率，並輸出標準 Word。詳解需要「看懂題目」，會呼叫 AI。

公式為單錢號 $...$，開檔後用 MathType Toggle TeX 轉換。
