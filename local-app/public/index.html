ONE-CLICK · 一鍵包

⚡ 一鍵：乾淨考卷 Word ＋ 題庫 23 欄 CSV

上傳掃描 PDF／照片，一次 Claude 讀圖同時產出「乾淨考卷 Word（可貼圖）」和「題庫 23 欄 CSV（Excel 可開、直接匯題庫）」。圖不裁，位置留〔含圖〕；約 4–5 分鐘。

建議：按下後趁 Claude 讀圖時，到題庫或下方截圖工具把圖框選好；跑完下載 Word 後把圖貼到〔含圖〕位置，CSV 則直接匯入題庫。
CROP TOOL · 截圖工具

🖼 截圖工具（從考卷框選裁圖）

上傳考卷 PDF，在頁面上拖曳框選圖／表，輸入題號即可下載成 Q題號.png（可直接丟進題庫「批次貼圖」，或貼到乾淨 Word 的〔含圖〕位置）。純在你的瀏覽器裁切，不上傳。

操作：在頁面上按住滑鼠拖出一個框 → 放開 → 輸入題號（題組圖勾「題組共用」）→ 下載。可一次下載全部成 ZIP。
SCAN CLEANUP · BETA

髒考卷整理

上傳掃描 PDF 或照片，重建成套用茲茲格式的可編輯 Word。處理時間較長；筆跡、圖表與看不清的文字會列入人工確認。

此功能需要主機已登入 Claude Code。請使用原始掃描檔；不要先用低解析度截圖或 OCR Word 取代原卷。
FAST CLEAN EXAM · 純文字

⚡ 快速乾淨考卷（純文字，自己貼圖）

上傳掃描 PDF 或照片，只重打文字與表格、不裁圖（圖的位置留「〔含圖：…〕」讓你自己框選截圖貼上），不含答案。速度最快，適合一份 3–5 分鐘搞定。

流程建議：按下後在等文字生成的同時，先到題庫系統把這份考卷的圖一張張框選截圖；文字檔下載後把圖貼到對應的〔含圖〕位置即可。

TIPS · 省 token / 省成本

使用建議

分清楚兩條路，成本差很多。

✅ 做考卷就用這個網頁純文字乾淨考卷、詳解生成都在這裡跑。每份是一次乾淨的呼叫，最省。
💬 只有要「改功能／修程式」才找 Claude 對話長對話會一直累積上下文，越後面越貴。
• 圖片自己在題庫系統框選截圖貼上 → 完全不花 token。
• 少貼大截圖給 AI（圖很吃 token）；能用文字描述就打字。
• 換主題就開新對話，別在同一條長對話裡一直接不同的事。
• 引擎走 claude-code、用的是 Claude 訂閱額度；訂閱制下用這網頁跑考卷不是按量計費，別短時間狂跑撞到用量上限即可。
