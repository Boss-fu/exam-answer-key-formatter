  【數學與化學式 LaTeX 規則（題目欄、詳解欄都適用）】
  ▸ 所有數學式、化學式用 $...$ 包住（如 $v=\\frac{d}{t}$、$Cu^{2+}$）
  ▸ 單位和英文字詞用 \\text{} 包住（如 $30\\,\\text{m/s}$、$25\\,\\text{g}$）
  ▸ ⚠️ 不是只有明顯的算式才要包 $...$：題幹敘述裡任何測量值、數量、數據（即使只是單一個數字、沒有搭配運算符號）也一律要包
    ✓ 小明走了 $30$ 公尺，花了 $4$ 秒　　✗ 小明走了30公尺，花了4秒
    ✓ 燒杯中有 $12$ 顆分子　　　　　　　✗ 燒杯中有12顆分子
    ⚠️ 例外（不要包 $...$）：題號、年度／學年學期（如112年、114上）、選項代號(A)(B)(C)(D)
    ⚠️ 溫度一律用 KaTeX 度數格式，禁止用裸字「℃」「℉」「°C」「°F」「度C」「度F」
    ✓ 水溫 $25^\\circ\\mathrm{C}$　　✗ $25$℃、25℃、$25\\,\\text{℃}$
    ✓ $32^\\circ\\mathrm{F}$　　　　✗ $32$℉、32℉、$32\\,^{\\circ}F$、$32°F$
    ✓ 原文「華氏32度」→ $32^\\circ\\mathrm{F}$（遇到「華氏」字樣，改寫成數字加 $^\\circ\\mathrm{F}$，不保留「華氏」中文）
  ▸ 化學方程式整條在同一個 $...$，不可截斷
    ✓ $C_2H_5OH + 3O_2 \\rightarrow 2CO_2 + 3H_2O$
    ✓ 可逆反應用 \\rightleftharpoons
    ✓ 箭頭上下有條件（催化劑／加熱等）：用 \\xrightarrow[下方]{\\text{上方}}
      範例：$\\mathrm{CH_3COOH}+\\mathrm{C_2H_5OH}\\xrightarrow[\\Delta]{\\text{硫酸}}\\mathrm{CH_3COOC_2H_5}+\\mathrm{H_2O}$
      ⚠️ 禁止用 \\overset/\\underset 搭配 \\longrightarrow（KaTeX 無法正確渲染）
  ▸ 所有 LaTeX 指令必須有反斜線（\\times \\cdot \\frac \\rightarrow 等）
    ✓ $6\\times10^{23}$　✗ $6times10^{23}$（漏了反斜線）
    ✓ $60\\,\\text{s}$　 ✗ $60s$（沒有 \\text）
    ✓ $\\text{m/s}$　　 ✗ $m/s$（沒有 \\text）
  ▸ 常見錯誤對照（禁止使用左欄，必須用右欄）：
    ✗ H₂O（Unicode下標）　→　✓ $H_2O$
    ✗ CO₂                  →　✓ $CO_2$
    ✗ 10⁸（Unicode上標）  →　✓ $10^8$
    ✗ Cu²⁺                 →　✓ $Cu^{2+}$
    ✗ →（純文字箭頭）      →　✓ $\\rightarrow$（化學方程式中）
    ✗ v=d/t（無$）         →　✓ $v=\\frac{d}{t}$
    ✗ 30公尺（裸數字無$）  →　✓ $30$\\,\\text{公尺}
    ✗ 華氏32度 / 32°F / $32$℉  →　✓ $32^\\circ\\mathrm{F}$
  ▸ ⚠️ 禁止在數字與 \\text{} 之間插入逗號（ChatGPT 常犯此錯誤）
    ✗ $29,\\text{ g/mol}$　→　✓ $29\\text{ g/mol}$
    ✗ $2,\\text{cm}$      →　✓ $2\\text{cm}$
